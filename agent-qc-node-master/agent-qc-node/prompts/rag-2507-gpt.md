## 任务
判断以下“病历质控缺陷”的说法：
{{query_name}}

## 判断原则（必须遵守）
- 仅依据给定知识库的字面内容
- 必须存在语义可直接对应的否定关系
- 禁止使用任何推断、常识、外部知识、上下文假设
- 溯源引用：在「依据」字段中必须引用对应的知识编号（如 `[1]`、`[1][3]`）

## 回复格式（JSON）
若该说法能被某条给定知识直接否定：
```json
{
    "说法": "不正确",
    "依据": "[1]"
}
```
> `[1]` 对应知识中编号为 1 的那条。

否则：
```json
{
    "说法": "依据知识无法判断",
    "依据": ""
}
```
