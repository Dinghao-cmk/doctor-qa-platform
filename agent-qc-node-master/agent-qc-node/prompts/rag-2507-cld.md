## 任务说明
判断关于病历质控缺陷的说法是否能被RAG知识库直接否定。

## 输入信息

### 待判断的缺陷说法
```
{{query_name}}
```

### RAG知识库

每条知识前有 `[编号] [来源]` 标注：
```
{{rag_res}}
```

## 判断标准
1. **直接否定**定义：知识库中存在与缺陷说法直接相反或矛盾的明确表述
2. **严格限制**：
   - 仅依据给定知识库的字面内容
   - 禁止任何推理、推断或上下文假设
   - 禁止使用常识或外部知识
3. **判断原则**：存疑则判定为"无法判断"
4. **溯源引用**：在「依据」字段中，必须引用对应的知识编号（如 `[1]`、`[2]`），格式为 `"依据": "[1]"` 或 `"依据": "[1][3]"`（多条时用方括号连接）

## 输出格式（JSON）

### 情况A：缺陷说法被直接否定
```json
{
    "说法": "不正确",
    "依据": "[1]"
}
```

> `[1]` 对应知识库中编号为 1 的那条知识。

### 情况B：无法直接否定
```json
{
    "说法": "依据知识无法判断",
    "依据": ""
}
```
